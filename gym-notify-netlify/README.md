# gym-notify-netlify

Напоминания для gym-app.html через вашего Telegram-бота, на Netlify.

Что приходит:
- 🌙 **в 22:00** — сводка на завтра: смена и все тренировки по времени;
- 🏋️ **за 1 час до каждой тренировки** (если несколько человек на одно время —
  одним сообщением);
- 🕒 **за 2 часа до каждой смены** — во сколько бы она ни начиналась.

Как устроено: функция `tick` запускается Netlify раз в 5 минут и проверяет,
не пора ли что-то напомнить. Каждое напоминание отправляется один раз —
отметки о отправленном хранятся в Netlify Blobs. Если тренировку записали,
когда до неё уже меньше часа, напоминание придёт сразу («Через 20 мин…»).

## Что нужно заранее

- Токен бота из @BotFather.
- Ваш личный Telegram `user_id` — напишите боту **@userinfobot**, пришлёт число.

## Деплой (так же, как вы уже деплоите бота на Netlify)

1. Загрузите содержимое этой папки в GitHub-репозиторий (как обычно) —
   `netlify.toml`, `package.json`, папку `netlify/functions/`.
2. В Netlify: **Add new site → Import an existing project** → выберите
   репозиторий. Build command и publish directory можно оставить пустыми —
   `netlify.toml` уже всё описывает.
3. **Site configuration → Environment variables** → добавьте:
   - `BOT_TOKEN` — токен бота
   - `TRAINER_ID` — ваш user_id
4. Задеплойте (Deploy site). Netlify сам найдёт `netlify/functions/*` и
   поднимет их как функции, а `tick.js` — как Scheduled Function (на вкладке
   **Functions** у неё будет пометка Scheduled).
5. Проверьте: откройте `https://ваш-сайт.netlify.app/.netlify/functions/health`
   — должно быть `{"ok":true,"hasData":false,...}` (данных ещё нет, это нормально).

## Дальше

Пришлите мне адрес вашего сайта (`https://ваш-сайт.netlify.app`) — я впишу
его в `gym-app.html` (`SYNC_URL`). Приложение начнёт при каждом сохранении
незаметно слать копию данных на `/api/sync`, а health-функция после этого
покажет `hasData: true` и реальные счётчики.

## Настройка времени

Всё меняется переменными окружения в Netlify (Site configuration →
Environment variables), код трогать не нужно:

| Переменная | По умолчанию | Что значит |
|---|---|---|
| `DIGEST_TIME` | `22:00` | во сколько по Москве присылать сводку на завтра |
| `TRAINING_LEAD_MIN` | `60` | за сколько минут до тренировки напоминать |
| `SHIFT_LEAD_MIN` | `120` | за сколько минут до смены напоминать |

После изменения переменных нажмите **Deploys → Trigger deploy**.
Напоминание может прийти с опозданием до 5 минут (функция проверяет раз в 5 минут).

## Как проверить

Запишите в приложении тренировку, которая начнётся через 30–50 минут, —
в течение 5 минут придёт напоминание «Через … мин». Или откройте в Netlify
вкладку **Functions → tick → Run now** (если доступно) и посмотрите лог.
